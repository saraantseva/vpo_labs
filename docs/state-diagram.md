# Диаграмма состояний: сущность Story

## 1. Выбор сущности

В качестве сущности с жизненным циклом выбрана **`Story`** (история блогера).
Она реализует конечный автомат с тремя состояниями и чёткими правилами переходов,
инкапсулированными в доменной модели.

**Файл диаграммы:** [`docs/diagrams/story-state.png`]

## 2. Состояния

| Состояние | Тип | Описание |
|---|---|---|
| `Draft` | Начальное (опционально) | Черновик. История создана, но ещё не опубликована. |
| `Published` | Начальное (по умолчанию) | Опубликована. Доступна в списке историй блогера. |
| `Archived` | Конечное | Снята с публикации. Финальное состояние. |

## 3. События и переходы

| # | Из | В | Событие | Условие | Действие |
|---|---|---|---|---|---|
| T-1 | — | `Draft` | `new Story(..., StoryStatus.Draft)` | description не пустой | Создание сущности |
| T-2 | — | `Published` | `new Story(...)` (default) | description не пустой | Создание сущности |
| T-3 | `Draft` | `Published` | `Publish()` | status == `Draft` | status ← `Published` |
| T-4 | `Published` | `Archived` | `Archive()` | status == `Published` | status ← `Archived` |
| T-5 | `Archived` | `Published` | `Unarchive()` | status == `Archived` | status ← `Published` |
| T-6 | `Draft` | `Archived` | `Archive()` | — | **запрещено**: `InvalidOperationException` |
| T-7 | `Published` | `Published` | `Publish()` | — | **запрещено**: `InvalidOperationException` |
| T-8 | `Archived` | `Archived` | `Archive()` | — | **запрещено**: `InvalidOperationException` |

## 4. Начальное и конечное состояния

- **Начальные состояния:** `Draft` (если создан явно), `Published` (значение по умолчанию).
- **Конечное состояние:** `Archived`. Переход `Archived → Published` формально
  возможен через `Unarchive()`, но в типичном бизнес-сценарии архив является
  финальным статусом перед удалением сущности.

## 5. Диаграмма

Диаграмма состояний приведена в отдельном файле:
- **Формат:** draw.io / PNG
- **Расположение:** `docs/diagrams/story-state.png`
- **Источник (если редактируется):** `docs/diagrams/story-state.drawio`

### Рекомендуемое обозначение на диаграмме
- Круг с точкой — начальное состояние (стрелка к `Draft` и `Published`).
- Двойной круг — конечное состояние (`Archived`).
- Прямоугольники со скруглёнными углами — состояния.
- Стрелки с подписями вида `событие [условие] / действие`.
- Красные стрелки с крестом — запрещённые переходы.
