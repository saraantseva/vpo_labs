# Blogers & Stories
Учебный проект, разработанный в рамках изучения .NET MAUI, MVVM и Clean Architecture.
Приложение для ведения базы блогеров и их публикаций.

## Используемые технологии

- .NET MAUI
- Entity Framework Core
- SQLite
- MediatR (CQRS)
- CommunityToolkit.MVVM
- CommunityToolkit.Maui

## Архитектура

Проект построен на Clean Architecture с разделением на четыре слоя:

- Domain — сущности предметной области (Bloger, Story)
- Application — бизнес-логика, CQRS запросы и команды
- Persistence — работа с базой данных, репозитории, Unit of Work
- UI — пользовательский интерфейс на .NET MAUI

## Запуск проекта

Восстановление зависимостей:

```
dotnet restore
```

Сборка для Windows:

```
dotnet build -f net10.0-windows10.0.19041.0
```

Сборка для Android:

```
dotnet build -f net10.0-android
```

Запуск приложения:

```
dotnet run --project Blogers.UI
```

## Основной функционал

**Блогеры**
- Просмотр списка всех блогеров
- Добавление нового блогера с указанием имени, даты рождения, никнейма и количества подписчиков
- Редактирование информации о блогере
- Удаление блогера

**Истории (Stories)**
- Просмотр списка историй, привязанных к выбранному блогеру
- Добавление новой истории с описанием, количеством лайков, просмотров и изображением
- Редактирование существующей истории
- Удаление истории
- Привязка изображения к истории с сохранением в локальное хранилище

**Дополнительно**
- Подсветка историй цветом в зависимости от количества лайков
- Отображение изображений на странице деталей истории
- Переход между страницами через Shell навигацию
